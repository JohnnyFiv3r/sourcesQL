# sourcesQL artwork

The quotation mark is the sourcesQL identity. These PNGs were supplied by the
project maintainer and are retained without image processing.

| File | Use |
| --- | --- |
| `sourcesql-mcp-icon-256.png` | MCP clients and compact app icons |
| `sourcesql-mcp-icon.png` | Full-size square icon and README |
| `sourcesql-mark-transparent.png` | Mark on a suitable background |

The icon uses mint `#9AE4C2` on dark green `#0E221D`. The interface uses dark
green `#17654B` for interactive elements on light backgrounds, and mint on dark
backgrounds. Text and focus indicators retain sufficient contrast.

The app embeds its own copy of the compact icon so rendering does not require
an image service. Update both copies together when replacing the artwork.
