# sourcesQL 0.2.0

Continue a research task without carrying the whole dataset through chat. Compact
checkpoints pin selected rows, fields, source versions, the exact correction
revision and pending work. Reopening checks access and dependencies without
running research; missing or stale records block continuation visibly.

Manual update checks now produce reviewable proposals. Existing findings and new
discovery stay separate, with retained source evidence and actual observation
times. Change Accept/Keep choices until publication; every choice remains in the
history. Publishing creates a saved successor and preserves the earlier table
and corrections. Missing search hits do not delete findings.

The initial path supports complete tables up to 100 rows and 200 KB, and
checkpoints up to 24 KiB. Accepted tables can be explicitly materialized for more
SQL. Hosted materialization may use a bounded Flight; inspecting checkpoints,
reviewing evidence and publishing do not.

The MCP App also removes the branding footer and keeps frame height stable when
selection actions appear. Hosted clients use one authenticated HTTPS connection;
no plugin ZIP is required. Refresh the existing host's tools, then reopen a saved
table. Claude's connector menu calls this **Refresh tools list**.

## Install or upgrade

```sh
python -m pip install --upgrade sourcesql==0.2.0
```

Use Python 3.12–3.14 on supported macOS or Linux, and Node.js 24 for the app and
guided personal-cloud setup. Start with the credential-free fixture demo before
configuring search providers. See [package installation](../package.md),
[personal cloud](../personal-cloud-setup.md) and [client connections](../clients.md).

Existing cloud setup workspaces retain their reviewed inputs. Keep their
receipts; a changed configuration belongs in a new reviewed plan. MotherDuck
Flights embed a pinned engine wheel, so a PyPI upgrade alone does not replace
an existing Flight. Upgrade its reviewed bundle and gateway fingerprints together,
and check fresh hosted acquisition separately from reopening saved results.
