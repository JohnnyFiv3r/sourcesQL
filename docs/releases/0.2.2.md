# sourcesQL 0.2.2

Fixture results now use `synthetic_fixture` consistently in top-level metadata
and their execution receipt. Results derived from private inputs retain
`private_derived` precedence. Previously saved results and receipts are retained.

A published manual update now shows its publication baseline and retained review
history when the parent later receives corrections. This prevents a misleading
stale-baseline rejection message on an already published successor. Unpublished
stale proposals still require a new check before acceptance or publication.

Hosted capabilities now report an explicitly configured worker-version pin
with its reviewed source and dependency fingerprints, or an unknown version
when no pin is configured. A configured pin is not proof of an executed run.
New setup carries the version from the validated Flight bundle.

Existing hosted Flights embed a reviewed wheel. Installing a package or updating
the gateway does not upgrade those workers; their versions and fingerprints need
separate alignment and verification.

Published as [v0.2.2](https://github.com/JohnnyFiv3r/sourcesQL/releases/tag/v0.2.2)
from commit `7e5fb9c834969d87633db2ae8ded779ff27553dc`. The
[release workflow](https://github.com/JohnnyFiv3r/sourcesQL/actions/runs/38846282859)
passed six installed-artifact checks: wheel and source distribution on Python
3.12, 3.13 and 3.14. Tagged artifact digests matched the qualified candidate bytes.
A fresh Python 3.13 public-PyPI install matched the published wheel digest and
passed fixture execution, saved reopening and offline bundle import without
credentials or provider calls. A network-disabled, read-only, nonroot Docker
smoke verified runtime version, two-row fixture execution, consistent
classification, saved reopening/export and current plus retained UI resources.
All four active hosted Flight definitions were aligned to the reviewed bundle.
Independent fixture query dispatch from ChatGPT and Claude produced two fresh
Pro runs that succeeded in 10.402 and 10.267 seconds with engine 0.2.2 and the exact
execution wheel. Result, receipt and `latest_receipt` classification agreed.
Provider and Hobby limits remained unchanged
with no new execution on those paths. Both actual ChatGPT and Claude apps rendered
the saved published successor and its revision-1 publication baseline after parent
refresh, without the misleading stale-baseline message. The current deployed UI
is `ui://sourcesql/research-2511fe6d0adf4f69.html`; historical a19 components remain
served. These checks do not qualify execution of every aligned worker or broader
live research in those hosts.

Fresh-account signup, wider live research quality, provider-specific Hobby host
