# sourcesQL 0.2.3

sourcesQL can retrieve a wider set of sources, narrow candidates with SQL, and
extract supported fields from the remaining documents. Saved research keeps
source dates and cell-level citations through supported projections and joins.

## Research

- Opt-in hosted Exa research supports complementary Auto searches, bounded
  parallel retrieval, source fetching and configured OpenAI extraction.
- Search planning stays with the host agent. Capabilities and concise tool
  descriptions identify the research entry point and available provider limits.
- SQL reuses retained source documents and evidence. Unsupported transformations
  preserve input-set evidence rather than inventing cell-level support.
- Final tables use friendly column labels, useful entity identifiers and explicit
  ordering. Intermediate discovery does not render automatically.

## Research app

- Manual update proposals appear in cell controls and an on-demand review panel.
  Accept/Keep choices remain adjustable until publication.
- Compact checkpoints, corrections, expansion, refresh and portable snapshots
  preserve their separate histories and stable identities.
- Capacity-blocked jobs have a saved job view with read-only status checks,
  explicit resume, accurate reset periods and optional provider billing links.
- Teal highlights use the sourcesQL brand color. Table selection does not grow
  the frame, and the former branding footer is removed.

## Installation and hosting

- Personal-cloud setup defaults to configured monthly reservations of 18,000
  maximum-runtime Flight seconds and $10 of search/model work. An optional daily
  Flight guard and existing provider policies can apply alongside them.
- Monthly guards count existing ledger rows in the dispatch transaction.
  Restarting or upgrading does not refund reservations.
- A configured application cap is separate from provider free credits, billing
  periods and account-wide spending. Adding a payment method does not raise the
  cap or resume saved jobs automatically.
- The MCP gateway reports its packaged version, with release checks covering the
  Python version and both Node package manifests.
- The release workflow qualifies the container before publication and pushes the
  same tested image ID, alongside qualified wheel and source distributions.

The hosted application serves one configured owner workspace. Search coverage,
source completeness and factual accuracy depend on the research task and retained
evidence; functional checks do not establish exhaustive coverage. Native free
quota and cooldown enforcement remain separate platform-specific checks.
