# sourcesQL 0.2.1

Fresh Vercel setup no longer sends `nodeVersion` to the project-creation endpoint,
which rejects that field. The deployment still explicitly selects Node.js 24.

Setup also refuses legacy personal scopes with a default team before creating
anything in Vercel. Those user records can report Hobby even when new projects
route to a Pro team. Choose the intended workspace and supply its team ID as both
`account_id` and `team_id`. Existing reviewed setup receipts are retained; a
changed configuration needs a new plan/workspace.

The patch changes no provider or Flight allowance, owner authentication, query
semantics, stored research or app presentation. Regression checks cover rejected
create fields, explicit destination selection, exact request recovery and the
retained deployment runtime pin. See [personal-cloud setup](../personal-cloud-setup.md)
for the corrected adoption steps.
